# Gerenciador de Tarefas em Python / Python Assignment Manager

[Português](#-português) | [English](#-english)

---

## 🇧🇷 Português

Projeto desenvolvido para a faculdade com foco em Programação Orientada a Objetos (POO).

### 🚀 Funcionalidades
- Adicionar novas tarefas com prioridade de 1 a 4.
- Concluir e reabrir tarefas.
- Editar descrição ou prioridade de forma dinâmica.
- Visualizar tarefas ordenadas automaticamente por prioridade.
- Tratamento de exceções robusto.

### 💻 Como executar
Certifique-se de ter o Python instalado e execute o arquivo no terminal:
```bash
python assignment_manager.py
```

## 🇺🇸 English

Project developed for university with a focus on Object-Oriented Programming (OOP).

## 🚀 Features
- Add new assignments with a priority level from 1 to 4.
- Complete and reopen assignments.
- Dynamically edit assignment descriptions or priorities.
- View assignments automatically sorted by priority.
- Robust exception handling.

## 💻 How to Run
Make sure you have Python installed, then run the script in your terminal:
```bash
python assignment_manager_en.py
```
